# 六点盲文排版台

本地运行的英语一级（Grade 1）六点盲文转写排版与识读 Web 应用。
Python / FastAPI 后端 + 原生 HTML/CSS/JavaScript 前端，**无需外网、无前端构建步骤**。

## 一条命令启动

需要已安装 Docker 与 Docker Compose（v2）。

```bash
docker compose up --build
```

启动后用浏览器访问：

> **http://localhost:8000**

停止：在终端按 `Ctrl+C`；后台方式可用 `docker compose up -d --build` 与 `docker compose down`。

端口被占用时，编辑 `docker-compose.yml` 中 `"8000:8000"` 的左侧端口即可（例如 `"18000:8000"`）。

## 不用 Docker 时（本地 Python 直跑）

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

同样访问 http://localhost:8000 。

## 功能与转写规则

### 盲文排版（原文 → 盲文）

- **输入约束**
  - 不超过 500 个 ASCII 字符：仅字母、数字、空格、换行；
  - 至少包含一个字母或数字；
  - 每个词只能全为字母或全为数字，非法字符与字母数字混写词会**定位到行、列**报错（点击错误可跳转到输入位置）；
  - 换行是**硬分段**；连续空格合并为**一个词间格**。
- **盲文转写（英语一级六点盲文）**
  - 点位编号：左列自上而下为点 1、2、3，右列为点 4、5、6；
  - 每个大写字母前加 **点 6** 大写标记；
  - 数字词以 **点 3456** 数字标记开头，数字 1～9、0 分别借用 a～i、j 的点位；
  - 输出使用 Unicode 盲文图案（U+2800 区段），词间使用 U+2800 空白盲文格。
- **排版**
  - 每行格数可设 10～40；
  - 词间格占 1 格；行首、行尾不留空格；
  - 普通词不在词内断行，**仅超宽词**可在字符间断开；断词行尾加 **点 36** 连字符；
  - 数字词跨行使，续行**重新加数字标记**；
  - 动态规划按以下顺序取最优：
    1. 断词次数最少；
    2. 行数最少；
    3. 各行剩余格数的平方和最小；
    4. 以上全相同时，取断点序列字典序最小者。
- **页面**：原文行与盲文格逐行对照；每格显示六点矩阵、盲文字符与说明（悬停查看点位）；
  显示每行用格/余格、断词与数字续行统计；支持**下载 Unicode 盲文 `.txt`**、一键复制。

### 盲文识读（盲文 → 原文）

- **输入约束**：粘贴不超过 **500 格**的 Unicode 六点盲文，允许盲文空格（U+2800）与换行。
- **识读规则**
  - 字母沿用一级点位还原；**⠠（点 6）** 只把紧随的一个字母转为大写；
  - 识读时持续记录**当前词的类型**（字母词 / 数字词）与**断词待续状态**；
  - **⠼（点 3456）** 使后续 a～i、j 点位分别读作 1～9、0；数字标记只能在词首
    （行首或盲文空格之后）**开启数字词**，或在数字词断行续行行首**重新起始**；
    数字状态到词间格或普通换行结束；
  - **⠤（点 36）** 仅作行尾断词标记：去掉该格及其后的换行并接续同一词；
    标记前必须有同一行内未结束的词，续行首格必须是**同一类型**的未结束词
    （字母续字母、数字以 ⠼ 重新起始）；盲文空格与普通换行终止词，普通换行保留。
- **报错**：孤立标记、未定义点位、行内连字符、标记前无未结束词、数字标记误入
  字母词、断行前后词类型不一致与不合法的数字续行均**按盲文行、列定位**
  （点击错误可跳转），且不输出部分解读文本。
- **页面**：顶部标签切换「盲文排版 / 盲文识读 / 双面点阵避让」三个视图；识读结果显示原文与格数/字符数/行数统计，支持一键复制。

### 双面点阵避让（正面 + 反面 → 最佳位移与冲突）

纸张双面打印时，需要让两面凸点尽量错开。顶部第三个标签页 **双面点阵避让**
（直接访问 http://localhost:8000 后点击「双面点阵避让」）即为此功能：

- **输入**：正面、反面两篇原文（与排版页相同的校验规则，错误按面别 + 行/列定位），
  共同行宽 w（10～40），最小点距（0.1～3.0 毫米，一位小数，默认 1.5）。
- **坐标**：零基行格 (r,c) 中，点 1～3 为 `(6c, 10r+2.5k)`，
  点 4～6 为 `(6c+2.5, 10r+2.5k)`，k=0～2，单位毫米；**只计凸点**。
  反面点映射到正面坐标：`(6(w-1)+2.5-x+dx, y+dy)`。
- **搜索**：dx、dy 各取 **-3～3 毫米、步长 0.1**，共 61×61 = **3721** 个位移
  全部遍历；两面点距**严格小于**最小点距即记一对冲突。所有坐标放大 10 倍用
  整数保存，距离用整数平方比较，无浮点误差。
- **择优**：按 **冲突对数 → dx²+dy² → dx → dy** 依次最小取最优位移。
- **结果**：返回最佳位移与**全部冲突点对**，每对标注两端的
  **面、行、格、点号**（行/格为 0 基）与实际点距；零冲突时页面显示
  **「可行」**，否则说明仍有冲突。页面叠加两面点阵（正面深色、反面蓝色、
  冲突点红色）并以红线连接冲突点对，悬停冲突表行可在叠加图中高亮对应点对；
  下方同时给出两面的逐格排版明细供核对。

## API

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| `POST` | `/api/typeset` | 请求体 `{"text": "...", "width": 20}`，返回排版结果；输入非法时 HTTP 422，`errors` 含行/列定位 |
| `POST` | `/api/decode` | 请求体 `{"text": "..."}`（Unicode 六点盲文，≤500 格），返回 `{"text": ...}` 识读结果；输入非法时 HTTP 422，`errors` 含盲文行/列定位，不返回部分结果 |
| `POST` | `/api/avoid` | 请求体 `{"front": "正面原文", "back": "反面原文", "width": 20, "min_distance": 1.5}`，复用校验与排版后遍历全部 3721 个位移，返回最佳 `shift`（`dx`/`dy`，毫米）、`feasible`、`conflict_count`、两面凸点坐标与全部冲突点对（含两端面/行/格/点号）；任一篇原文非法时 HTTP 422，错误带 `side`（front/back）与行/列定位 |
| `GET` | `/api/health` | 健康检查 |

例：

```bash
curl -s -X POST http://localhost:8000/api/typeset \
  -H 'Content-Type: application/json' \
  -d '{"text":"Hello 2026","width":16}'

curl -s -X POST http://localhost:8000/api/decode \
  -H 'Content-Type: application/json' \
  -d '{"text":"⠠⠓⠑⠇⠇⠕⠀⠼⠃⠚⠃⠋"}'

curl -s -X POST http://localhost:8000/api/avoid \
  -H 'Content-Type: application/json' \
  -d '{"front":"Hello Braille","back":"Braille reading","width":16,"min_distance":1.5}'
```

## 离线说明

镜像基于 `python:3.11-slim`，仅在**构建镜像时**从 PyPI 拉取三个 Python 依赖；
运行后所有资源（HTML/CSS/JS、字体回退均使用系统字体）均由本服务自身提供，
不访问任何 CDN 或外部服务，可在断网环境中使用。

├── tests
│   ├── test_braille.py    # 排版引擎测试（含与独立 DP 的随机对照）
│   ├── test_reader.py     # 识读引擎测试（含排版→识读往返对照）

├── docker-compose.yml
├── requirements.txt

## 测试

```bash
pip install pytest
python3 -m pytest tests/ -q
```

测试覆盖转写规则、识读规则、报错定位、超宽词断行、数字续行标记、各优化目标优先级、
排版→识读往返一致性，以及双面点阵的坐标公式、阈值严格小于、位移择优优先级与冲突端点
标注；排版以独立实现的记忆化 DP、避让以朴素 O(点²×位移²) 全矩阵枚举为基准做随机对照。
